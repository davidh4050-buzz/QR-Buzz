# QR Buzz

v0.2.0 - Local QR Code Generator for WordPress

## Features
- Admin QR generator
- URL to QR conversion
- Local SVG QR code generation
- No external QR API calls
- Safer admin form handling with nonce verification

## Notes
v0.2.0 generates QR codes inside the plugin instead of calling an external API. This release supports byte-mode URLs up to 42 characters.
